function(app, ...)

getCrashlytics(app, options)

This API is provided as a preview for developers and may change based on feedback that we receive. Do not use this API in a production environment.

Returns the default Crashlytics instance that is associated with the provided FirebaseApp. If no instance exists, initializes a new instance with the default settings.

Signature:

export declare function getCrashlytics(app?: FirebaseApp, options?: CrashlyticsOptions): Crashlytics;

Parameters

Parameter Type Description
app FirebaseApp The FirebaseApp to use.
options CrashlyticsOptions CrashlyticsOptions that configure the Crashlytics instance.

Returns:

Crashlytics

The default Crashlytics instance for the given FirebaseApp.

Example

const crashlytics = getCrashlytics(app);

function()

breadcrumbs()

(EXPERIMENTAL) Enables Crashlytics breadcrumb and trace telemetry collection when passed in CrashlyticsOptions.features.

When enabled, Crashlytics collects OpenTelemetry spans (such as Fetch, XMLHttpRequest, and Document Load) and breadcrumb logs (such as navigation events, Web Vitals, user actions, and visibility lifecycle events), buffering them in memory and exporting them when an error occurs.

Signature:

export declare function breadcrumbs(): CrashlyticsFeature;

Returns:

CrashlyticsFeature

Example

import { getCrashlytics, breadcrumbs } from 'firebase/crashlytics';

const crashlytics = getCrashlytics(app, {
  features: [breadcrumbs()]
});
