Schema class

Parent class encompassing all Schema types, with static methods that allow building specific Schema types. This class can be converted with JSON.stringify() into a JSON string accepted by Agent Platform Gemini API and Gemini Developer API REST endpoints. (This string conversion is automatically done when calling SDK methods.)

Signature:

export declare abstract class Schema implements SchemaInterface

Implements: SchemaInterface

format string Optional. The format of the property. Supported formats:

  • for INTEGER type: "int32", "int64"
  • for STRING type: "email", "byte", etc
items SchemaInterface Optional. The items of the property.
maxItems number The maximum number of items (elements) in a schema of SchemaType array.
minItems number The minimum number of items (elements) in a schema of SchemaType array.
nullable boolean Optional. Whether the property is nullable. Defaults to false.
type SchemaType Optional. The type of the property. This can only be undefined when using anyOf schemas, which do not have an explicit type in the OpenAPI specification.
