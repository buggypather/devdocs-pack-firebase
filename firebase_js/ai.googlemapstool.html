GoogleMapsTool interface

A tool that allows a Gemini model to connect to Google Maps to access and incorporate location-based information into its responses.

Important: If using Grounding with Google Maps, you are required to comply with the "Grounding with Google Maps" usage requirements for your chosen API provider: Gemini Developer API or Agent Platform Gemini API (see Service Terms section within the Service Specific Terms).
