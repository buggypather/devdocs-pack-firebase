RangeWindowFrame interface

This API is provided as a preview for developers and may change based on feedback that we receive. Do not use this API in a production environment.

Defines a range-value based window frame relative to the sort value(s) of the current document.

Window Functions SDK features are in preview until the backend feature launches. Look for launch announcement at: https://docs.cloud.google.com/firestore/docs/release-notes

One or more sort expressions must be specified on the enclosing WindowSpec when using a range window frame. Range frames with numeric or time-unit offsets require a single numeric or timestamp sort expression, whereas frames bounded only by 'current' and 'unbounded' support multiple sort expressions and non-numeric sort values (such as strings or booleans).

Signature:

export declare interface RangeWindowFrame

Can be: - A number specifying the value-based offset from the current document's sort value. A positive offset adds to the current document's sort value (looking into the future).
