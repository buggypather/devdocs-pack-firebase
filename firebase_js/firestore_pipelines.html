The returned Promise can be used to track the progress of the pipeline execution and retrieve the results (or handle any errors) asynchronously.

InsertStageOptions

Options for defining an insert stage in a Pipeline.

The target document path for each inserted document is determined by the combination of collection and documentIdExpression: - **Neither set:** Inserts each document at its existing __name__ path.
