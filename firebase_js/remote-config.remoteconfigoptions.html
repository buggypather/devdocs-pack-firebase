RemoteConfigOptions.initialFetchResponse

RemoteConfigOptions.templateId

Warning: This API is now obsolete.

Fetching server templates from client apps is not supported. Server templates ("firebase-server") can only be read by the Admin SDK and are rejected by client fetch and real-time requests. This option will be removed in a future major release.

The ID of the template to use. If not provided, defaults to "firebase".

Signature:

templateId?: string;
