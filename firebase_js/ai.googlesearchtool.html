GoogleSearchTool interface

A tool that allows a Gemini model to connect to Google Search to access and incorporate up-to-date information from the web into its responses.

Important: If using Grounding with Google Search, you are required to comply with the "Grounding with Google Search" usage requirements for your chosen API provider: Gemini Developer API or Agent Platform Gemini API (see Service Terms section within the Service Specific Terms).
